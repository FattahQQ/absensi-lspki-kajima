# 🚀 Sistem Absensi LSPKI KAJIMA

Aplikasi web sederhana untuk pencatatan kehadiran (absensi) harian berbasis HTML, CSS, dan JavaScript.

## 📌 Fitur Utama
- **Autentikasi:** Form Login & Register dengan penyimpanan akun lokal (*LocalStorage*).
- **Dashboard Absensi:** Tampilan jam *real-time* serta tombol **Absen Masuk** dan **Absen Keluar**.
- **Riwayat Kehadiran:** Mencatat dan menampilkan riwayat absensi pengguna secara permanen di browser.

## 🛠️ Teknologi yang Digunakan
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
- **Storage:** Web Storage API (LocalStorage)
- **Version Control:** Git & GitHub
